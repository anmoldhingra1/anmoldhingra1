# Anmol Dhingra

### Founder & CEO of [Rerato](https://www.rerato.com). We make AI hosts.

A host is a voice with a personality that runs the moment: a game, a class, a gathering, for one person or a whole room. Our first product is [Trivana](https://trivana.ai): turn any topic, link or document into a show run by an AI host, in about a minute and in ten languages. Play it alone, in a live room where one screen hosts and every phone is a buzzer, or inside ChatGPT.

Before Rerato, nine years of applied AI in regulated environments: cybersecurity, financial services, NLP, voice, graph ML and MLOps. I still write code every day and like owning the whole loop, from model behavior to runtime to what happens in the room.

### Problems I like

- Voices that stay in character, in every language
- Hosts that react to each answer as it lands
- Live rooms: one screen hosts, every phone is a buzzer, nobody signs up
- Grounded generation: every question checked against its source
- Ruthless evaluation before anything reaches a player
